Mihon / Mangayomi → AnymeX
Browser-based backup converter

Convert your manga library

Upload a Mihon backup JSON, a Mangayomi .backup file, or a plain CSV alongside an AnymeX template. The browser queries AniList and downloads a ready-to-restore .anymex file — no Python, no install.

Step 1

In Mihon, go to More → Backup & restore → Create backup. Save the .tachibk file to your device.

Step 2

Open backup.mihon.tools, load your .tachibk, then click Download → JSON. That JSON file is your input here.

Step 3

Upload the JSON below, add your AnymeX template, click Parse → Fetch → Build. Restore the .anymex in AnymeX → Data Management.

Step 1

In Mangayomi, go to More → Settings → Backup & restore → Create backup. Save the .backup file — it contains your full manga library.

Step 2

Use the Mangayomi backup (.backup) input below — no conversion needed. Status and chapter progress are imported automatically.

Step 3

Add your AnymeX template, click Parse → Fetch → Build. Restore the .anymex in AnymeX → Data Management → Restore backup.

Format

No header row expected. First column must be the manga title.

Columns

Title, Status, ChaptersRead, ListName — only Title is required; the rest default to PLANNING / 0 / Migrated.

Status values: CURRENT, PLANNING, COMPLETED, DROPPED, PAUSED, REPEATING.

Where to get it

Open AnymeX → Data Management → Backup Data. Even a 1-manga backup works as template.

Why needed

The template supplies user-specific fields (userId, settings) so your restored backup looks native.
