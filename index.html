Mihon &
Mangayomi
→ AnymeX

Upload a Mihon backup JSON, a Mangayomi .backup file, or a plain CSV alongside an AnymeX template. The browser queries AniList and downloads a ready-to-restore .anymex file.

How to get your backup files expand for steps
▾
Step 01

In Mihon, go to More → Backup & restore → Create backup. Save the .mihon file to your device.

Step 02

Open backup.mihon.tools, load your backup, then click Download → JSON. That JSON file is your input here.

Step 03

Upload the JSON below, optionally add an AnymeX template, click Parse → Fetch → Build. Restore the .anymex in AnymeX → Data Management.

Step 01

In Mangayomi, go to More → Settings → Backup & restore → Create backup. Save the .backup file.

Step 02

Use the Mangayomi backup input below — no conversion needed. Status and read progress import automatically.

Step 03

Optionally add an AnymeX template, click Parse → Fetch → Build. Restore the .anymex in AnymeX → Data Management → Restore backup.

Format

No header row expected. First column must be the manga title.

Columns

Title, Status, ChaptersRead, ListName — only Title is required; the rest default to PLANNING / 0 / Migrated.

Status values: CURRENT PLANNING COMPLETED DROPPED PAUSED REPEATING

Where

Open AnymeX → Data Management → Backup Data. Even a 1-manga backup works as template.

Why

Supplies user-specific fields (userId, settings). Fully optional — a fresh file is built automatically if skipped.
