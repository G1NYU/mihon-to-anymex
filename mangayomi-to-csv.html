Mangayomi .backup → CSV extractor

Mangayomi backups are SQLite databases. This tool reads the .backup file entirely in your browser (nothing is uploaded), extracts your manga titles, and exports a CSV — ready to paste into the main converter.

Step 1 — Upload your .backup file
🟢 Where to find it: Mangayomi → More → Settings → Backup & restore → Create backup. The file is named something like mangayomi_YYYY-MM-DD_….backup.

The file stays 100% local — no server involved.
